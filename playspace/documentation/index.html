1. Overview & Architecture

Welcome to the official developer documentation for PlaySpace — Kids Indoor Trampoline & Soft Play Center template.

Key Features

  • Pure Vanilla Frontend: 100% HTML5, CSS3, and Vanilla JavaScript. Zero build tools, bundlers, npm dependencies, or backend frameworks required.
  • Strict 3-Color Visual Palette: Exclusively Black (#000000), White (#FFFFFF), and Yellow (#FFCC00) across both light and dark modes.
  • Integrated Navigation Bar: Clean layout with no top announcement bar. Dark Mode and LTR/RTL toggles fit seamlessly directly into the main navbar.
  • Complete Modular System: 15 structured CSS files and 16 clean JavaScript modules with clear responsibilities.
  • Dual Portals Included: Complete Parent Self-Service Portal (14 pages) and Admin Operations Console (13 pages).
