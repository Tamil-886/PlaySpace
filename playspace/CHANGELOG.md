# Changelog

All notable changes to the PlaySpace template are documented in this file.

## [2.0.0] - 2026-10-13
### Added
- Complete project architecture overhaul to pure HTML5, CSS3, and Vanilla JavaScript.
- Strict 3-Color UI palette implementation: Black (`#000000`), White (`#FFFFFF`), and Yellow (`#FFCC00`).
- Integrated navigation bar with Dark Mode and LTR/RTL toggles placed neatly inside the main navbar (removed legacy top announcement bar).
- 20 complete public website pages (including 2 unique homepages, attractions, parties, pricing, safety, and forms).
- 14 complete Parent Self-Service Portal pages (dashboard, child profiles, waiver management, 4-step booking wizard with canvas signature pad, digital punch pass wallet, printable invoice).
- 13 complete Admin Operations Console pages (live facility occupancy gauge, capacity alert triggers, canvas charts, check-in desk, schedule calendar, CRM directory, party room monitors).
- 15 modular CSS stylesheets covering reset, typography, layout, components, booking flow, dashboard, admin, dark mode, RTL, responsive, and print styles.
- 16 modular Vanilla JavaScript files.
- 7 comprehensive developer documentation guides.
- SVG brand logos (`logo.svg`, `logo-dark.svg`, `favicon.svg`) matching brand bounce badge and typographic hierarchy.
